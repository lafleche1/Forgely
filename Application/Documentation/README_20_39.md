# Forgely 20.39 — objectifs uniquement

- Le formulaire de jets cibles ne demande plus de choisir ou saisir un équipement.
- Le nom est issu exclusivement de l'identification automatique déjà présente.
- La colonne « Jet actuel » est en lecture seule et se rafraîchit à partir des lectures OCR stabilisées et attribuées à l'équipement confirmé.
- Si l'équipement ou le jet n'est pas confirmé, l'interface affiche « Non détecté ».
- Seuls les jets souhaités sont enregistrés. Leur enregistrement ne réinitialise plus la session OCR.
- Le résumé de progression utilise le jet OCR courant, jamais un ancien jet manuel sauvegardé.

La capture OCR réelle doit être validée sur Windows avec DOFUS ouvert.
