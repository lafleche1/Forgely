# Forgely 0.20.13 — quatre thèmes

Ouvrir **⋯ Plus → Apparence · 4 thèmes**. Le choix est appliqué sans redémarrage et enregistré dans `~/.forgely/apparence.json`.

Thèmes : DOFUS classique, Minimal épuré, Sombre immersif, Fantaisie turquoise. Les quatre maquettes précédentes sont des inspirations : cette version applique les palettes à l’interface Tkinter existante, sans reproduire exactement les illustrations ni inventer d’équipement.

La logique de forgemagie, l’OCR et les icônes de runes ne changent pas.
