# Forgely 0.20.11 — style adouci

- Titres et conseils : Trebuchet MS (police plus ronde que Bahnschrift), puis Arial Rounded MT Bold / Segoe UI en repli.
- Texte courant : Segoe UI, lisible sous Windows.
- Boutons réellement arrondis, dessinés dans Tkinter Canvas, sans police ou bibliothèque supplémentaire.
- Panneaux plus doux : suppression des bordures carrées visibles.
- Couleurs DOFUS sobres, catalogue d’icônes de runes conservé.
- Les cartes utilisent toujours une structure rectangulaire interne de Tkinter ; les boutons sont les éléments arrondis dans cette livraison.
- Aucune modification des calculs, de la reconnaissance ou de la collecte.
