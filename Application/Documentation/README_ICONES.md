# Icônes réelles de runes

Le mini-overlay affiche désormais les PNG déjà présents dans `catalogue_dofus3/`, référencés par `index.json` et provenant de captures utilisateur. La correspondance est stricte : pas d'icône inventée ni d'association approximative. Les conseils sans rune reconnue affichent « FM ».

Exemple : « Ra Vi ×1 » utilise `rune_025.png`. Les images sont utilisées localement et non redistribuées séparément du projet. Le reste des pictogrammes génériques de la fenêtre principale n'a pas été remplacé par des ressources officielles non disponibles.
