# Forgely 0.20.9 — habillage sobre, inspiré des ateliers de DOFUS

- Interface principale : brun anthracite, beige parchemin, bordures bronze et accent vert mousse ; fond uni, sans paysage généré.
- Identité typographique FORGELY, sans logo fictif se faisant passer pour une ressource officielle.
- Mini-overlay compact 184 × 66, voyant atelier conservé, instruction principale lisible.
- Les 105 icônes de runes du catalogue existant sont conservées sans altération ; cette version ne prétend pas que leurs droits ou leur correspondance DOFUS 3 sont validés.
- Aucune mécanique de jeu, base statistique, OCR ou stratégie n'a été modifiée intentionnellement.
- Pour une identité visuelle exactement fidèle à DOFUS 3, les ressources doivent être vérifiées et utilisées conformément à leurs droits.
- Tests logiciels possibles ici, mais interface Windows/DOFUS 3 non validée en situation réelle.

Démarrage : `installer_windows.bat` puis `demarrer_forgely.bat` sous Windows.
