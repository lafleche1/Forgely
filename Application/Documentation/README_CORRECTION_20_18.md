# Forgely 0.20.18 — Correction du menu et de l’apparence

Le bouton **Apparence · 4 thèmes** est désormais visible immédiatement en haut de « ⋯ Plus ». Le reste du menu défile à la molette et sa hauteur s’adapte à l’écran. La fenêtre principale s’ouvre avec une taille adaptée à l’écran.

## Installation

Extraire le ZIP dans un **nouveau dossier**, puis double-cliquer sur `demarrer_forgely.bat` (après `installer_windows.bat` si nécessaire). Il ne s’agit pas encore d’un installateur EXE autonome.

## Limites

L’interface complète reste fondée sur Tkinter et certains panneaux peuvent nécessiter un défilement ou une résolution supérieure. Test visuel sur Windows à effectuer.
