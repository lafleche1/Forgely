# Forgely 0.20.12 — Panneaux et mini-overlay arrondis

- Les trois panneaux principaux ont désormais des coins arrondis avec lissage via Pillow.
- Les boutons arrondis et la typographie douce de 0.20.11 sont conservés.
- Le mini-overlay dispose d'une silhouette arrondie sur Windows grâce à la transparence de couleur. Les autres plateformes conservent un fond rectangulaire de secours.
- Les fenêtres secondaires natives et les champs de saisie Tk/ttk ne sont pas tous arrondis : cette version cible la fenêtre principale et le mini-overlay.
- Aucune modification du moteur de FM, de l'OCR ou des statistiques.
