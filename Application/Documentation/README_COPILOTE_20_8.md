# Forgely 0.20.8 — Copilote joueur

Ajouts : une instruction principale (rune ×1), signal STOP lorsque **tous** les objectifs sont atteints sur un jet OCR stabilisé et un puits lu, modes jet propre/parfait/exo, risque qualitatif sans taux fictif, écran de budget manuel, maintien du laboratoire séparé et de l’historique.

**Limites connues :** les modes ne constituent pas encore des stratégies optimisées distinctes ; le risque est une précaution qualitative, pas une probabilité ; les prix sont manuels et les dépenses ne sont pas chiffrées sans comptage de runes audité. Le diagnostic OCR et la détection de l'atelier restent dépendants de la configuration DOFUS. Aucune action n'est effectuée dans le jeu. Tester sous Windows en atelier avant utilisation réelle.
