# Icônes de runes dans la fenêtre principale

La carte « Prochaine rune » affiche désormais la même icône locale que le mini-overlay.
La résolution est exacte via `forgely_rune_icons.rune_icon_path` et le catalogue `catalogue_dofus3/index.json`.
Aucune correspondance ambiguë n’est devinée : dans ce cas, un pictogramme neutre « FM » est affiché.
L’image est redimensionnée en mémoire sans modifier les fichiers originaux.
Les conseils, l’OCR et les statistiques sont inchangés.
