# Forgely 0.20.14 — Diagnostic OCR en direct

Menu « Plus » → « Diagnostic OCR » : rapport actualisé toutes les 1,5 secondes,
avec statut de l'observateur, confirmation de l'équipement et du jet,
présence du texte par zone, conflits OCR/icône et motifs de vérification.

Le rapport peut être copié manuellement. Les recadrages OCR ne sont exportés
que sur action explicite du joueur, lorsque l'observateur tourne.

Attention : la présence de texte n'est **pas** une mesure de précision OCR.
Le diagnostic n'établit aucune probabilité de reconnaissance correcte.
Il faudra mesurer les erreurs sur des captures annotées de DOFUS sous Windows.
