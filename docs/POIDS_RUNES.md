# Poids des 105 runes — client 3.7.13.17

Cette table est dérivée des fichiers du client Ankama, extraits et publiés par un tiers. Elle ne constitue pas une table publiée ou certifiée directement par Ankama. Les pages officielles testées n’étaient pas accessibles (HTTP 403). Aucune certification officielle n’a été inventée.

Les données numériques ci-dessous proviennent uniquement de la release [dofus-sqlite v6.0_3.7.13.17](https://github.com/ledouxm/dofus-sqlite/releases/tag/v6.0_3.7.13.17). Les requêtes exploratoires DofusDB n’ont pas servi à produire le référentiel livré.

Poids = gain × effectPowerRate. La valeur brute float32 est conservée dans le JSON ; calcul sur la valeur arrondie à 6 décimales pour éliminer les artefacts tels que 0.20000000298. Aucun taux SC/SN/EC ne découle de ces poids. Le poids d’inventaire realWeight n’est jamais utilisé.
