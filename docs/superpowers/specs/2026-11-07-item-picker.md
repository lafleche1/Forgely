# Sélection manuelle et jet souhaité

Maquette approuvée le 7 novembre 2026. Parcours : Coiffe/Cape/Anneau/Amulette/Ceintures/Bottes/Arme → objet nommé avec sa véritable icône → valeurs cibles → démarrage. Le nom sélectionné remplace l'attente OCR du nom. Les jets actuels et le puits restent lus dans DOFUS. Un changement d'objet en jeu suspend l'association et exige une nouvelle sélection ; ne jamais apprendre automatiquement un logo sous un nom choisi manuellement.

Utiliser les identifiants de type du catalogue local plutôt qu'une déduction fragile du nom. Charger les icônes locales disponibles ou une source publique validée, en conservant une indication explicite des images manquantes. Ne pas inventer les bornes naturelles absentes ni les jets actuels.
