# Forgely v22 — refonte de l'atelier

**But :** remplacer l'ancien écran par un atelier de bureau moderne, lisible et cohérent avec le mode flottant.
**Choix :** graphite et émeraude par défaut, navigation latérale, caractéristiques au centre, assistance à droite, historique de session en bas. Conserver Python/Tkinter, tous les outils et les règles OCR existantes. L'utilisateur demande l'exécution autonome ; les choix de mise en page sont pris ici pour avancer.

## Étapes
- Vérifier les états du tableau (absence de lecture, provisoire, confirmé, cible), sans valeur fictive ni confusion entre objectif et observation.
- Construire un module de présentation indépendant du moteur OCR ; conserver les attributs des widgets utilisés par ses callbacks.
- Appliquer la nouvelle palette, des composants plus sobres, une typographie nette et un badge flottant cohérent.
- Vérifier l'affichage réel sous Tk, le redimensionnement, la navigation, le changement de thème, l'actualisation des lectures et les états inconnus.
- Exécuter les tests, effectuer une revue, publier dans le dépôt privé et vérifier GitHub Actions.

## Contraintes
Aucune probabilité fictive. Une lecture provisoire reste identifiée comme telle. Aucun changement dans la collecte, les décisions de rune, la capture et la persistance OCR. Les données affichées au démarrage restent vides tant que le jeu n'est pas lu.
