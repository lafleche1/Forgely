# Suppression des prix

Objectif demandé : aucun prix, budget ou coût monétaire dans les conseils,
l'entraînement, les simulateurs et leurs interfaces. Le jet cible seul guide
le conseil. Conserver les observations et les anciens rapports, sans les réécrire.

Approche retenue : supprimer les contrôles et branches de calcul ; accepter
les anciens paramètres d'appel lorsqu'utile, mais les ignorer. Les anciennes
préférences économiques sont normalisées vers Chances maximales. Les nouvelles
politiques ne contiennent plus d'état ni de métrique monétaire ; versionner
leur format pour empêcher la reprise d'une politique contrainte par des prix.

- [x] Tests de non-influence des anciens prix/budgets et migration des préférences.
- [x] Retirer calcul économique du conseil, RL et formation ; nettoyer rapports.
- [x] Retirer formulaires, commandes et descriptions des interfaces Tk.
- [x] Adapter les tests obsolètes et vérifier les fenêtres réellement créées.
- [x] Suite complète avec Tesseract et répertoire temporaire autorisé ; lanceur.

Choix local : garder uniquement la compatibilité de signature, jamais de calcul
monétaire caché. Le stock de runes et la limite du nombre de poses demeurent
des contraintes non monétaires.

Vérification : 1 330 tests réussis, 25 ignorés et 42 sous-tests réussis dans
la suite globale. 10 tests complémentaires réussis après retrait du dernier
outil de coût inutilisé. Inspection des widgets Tk de l'entraînement, du
conseil et de l'atelier : aucun contrôle monétaire. Exécutable d'entraînement :
code de sortie 0, format tabular-no-currency-3, configuration et bilan sans
prix, budget ou coût. Anciens rapports conservés, nouvelles politiques à réentraîner.

Revue indépendante : aucun défaut important trouvé ; paramètres restants
uniquement pour compatibilité ignorée ou rejet d'anciennes politiques.
