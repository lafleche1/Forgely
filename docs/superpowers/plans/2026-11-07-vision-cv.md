# Vision classique — modules autonomes

Spécification explicite utilisateur : MSS, template matching OpenCV, rectangles
relatifs, filtrage HSV vert/rouge et architecture d'un lecteur de glyphes local.
Pas de Tesseract, EasyOCR, PaddleOCR ou VLM dans cette brique.

- [x] `forgely_cv/capture.py` : MSS persistant sur son thread, BGRA vers BGR,
  pixels physiques, cadence cible sans accumulation de captures.
- [x] `geometry.py`, `detection.py` : profils calibrés, matchTemplate,
  coordonnées absolues, rejet d'une ancre absente ou ambiguë.
- [x] `masking.py` : HSV, deux plages rouges, masque binaire noir/blanc.
- [x] `glyphs.py` : contours, composants détachés, références par taille,
  comparaison XOR, caractère inconnu explicite.
- [x] `pipeline.py`, `__main__.py` : calibration, run, benchmark, extraction
  d'échantillons à étiqueter, sans toucher aux observations métier existantes.
- [x] Vérifier tests synthétiques, commandes et capture MSS réelle ; mesurer
  séparément capture et traitement ; documenter les limites.

Les images de police/ancre réelles sont nécessaires ; aucun faux dictionnaire
DOFUS fourni. Les couleurs ne certifient pas SC/SN/EC. Ni 5 ms de bout en bout,
ni >30 FPS sans effet sur le jeu ne peuvent être garantis sans mesure en jeu.
L'intégration au calcul du puits reste hors de cette première brique.

Verification : 11 tests cibles et suite generale 1361 reussis, 24 ignores, 42 sous-tests. Revue independante sans anomalie importante. MSS ROI320x180 p95=7.60412ms ; traitement synthetique800x480 sans glyphes p95=.39776ms. Objectif global5ms non atteint.
