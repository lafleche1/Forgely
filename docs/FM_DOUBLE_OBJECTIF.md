# Deux modes de recommandation

Le choix **Chances maximales** ou **Budget optimisé** est conservé dans les paramètres. Les 105 prix Tylezia sont activés une seule fois, après sauvegarde des anciennes préférences. Les modifications ultérieures sont conservées.

Les deux modes respectent les mêmes cibles et contraintes. Une remontée naturelle ciblée disponible précède une finition over/exo. Le mode économique divise les scores positifs par (1 + prix unitaire) lorsque tous les prix candidats sont connus. Un prix manquant suspend cette pondération ; il ne vaut jamais zéro. Aucun budget dur ne bloque une cible. Ce classement ne garantit pas le coût minimal du jet complet.

Les probabilités de passage restent séparées des prix. Le détail expose un scénario SC et des branches SN/EC conditionnelles aux pertes réellement observées.
